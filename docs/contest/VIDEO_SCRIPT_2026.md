# OpsDeck contest video script

**Status:** 100-second recording plan; not recorded or uploaded.

**Capture:** use the live Safe Demo at <https://kennethjsmithdev.github.io/OpsDeck/>. Keep the visible `SAFE DEMO` / `DEMO DATASET` labels in frame. Do not enter credentials or imply that this browser session is connected to IRIS.

| Time | Screen action | Narration |
|---|---|---|
| 0:00–0:10 | Show the Overview and the demo labels. | “This is OpsDeck, a browser-based operations console for InterSystems IRIS. This walkthrough uses sanitized demo data; it is not connected to a live instance.” |
| 0:10–0:25 | Point at Server identity and Web applications. | “The Overview puts the demo identity and a bounded application summary together. The read-back indicator shows what was compared.” |
| 0:25–0:40 | Open Applications; select `/opsdeck`; show its detail. | “In Applications, select a web app to keep its identity and details in view. The native product also supports REST-service discovery and bounded API summaries.” |
| 0:40–0:58 | Switch demo personas using Demo Access; show navigation/scope changes. | “Changing the demo persona changes the projected workspace, not the sample dataset. In the live product, UI visibility is not an authorization grant; IRIS remains authoritative.” |
| 0:58–1:15 | Visit Tasks, System, then Logs. | “Tasks, System, and Logs bring operational information into the same workspace. Empty, unavailable, denied, and failed states stay distinct.” |
| 1:15–1:38 | Open Evidence, pause on Verified and Unverified/Blocked cards. | “Evidence makes qualification boundaries visible. A successful neighboring read does not prove an unfinished workflow. The safe demo explains the interaction model; it does not prove live IRIS behavior.” |
| 1:38–1:40 | End on the product and repository links. | “Review the release guide for scope.” |

**Before recording:** the timing rows total 100 seconds. Keep the video between 90 and 120 seconds after editing. Show only the currently published v0.2.0/OEX scope unless a later release is actually published and qualified.
