# Contextual IRIS learning — acceptance staging

> Product-safe staging record. This does not assert a Community Opportunity award or final implementation claim.

OpsDeck already provides two optional learning projections:

- **IRIS concepts in this view** — collapsed contextual explanations tied to selected workspaces.
- **ObjectScript snippet library** — inert, lazy-loaded plain-text examples with no execution authority.

## Intended compact extension

A beginner-learning topic is represented by a small identity and expanded only when requested:

`LearningTopicId → title → explanation → related SemanticRefs → optional snippet refs`

Candidate topic groups:

- IRIS basics
- operational state/evidence semantics
- packages and administration
- Embedded Python / Vector Search / semantic investigation
- ObjectScript / SysAdmin API basics

## Product contract

Any final implementation must preserve:

- collapsed/lazy presentation
- static escaped educational content
- no execution or privilege changes
- no duplicate authoritative operational state
- removability without affecting OpsDeck behavior
- compact/mobile usability

The exact Ideas Portal mapping and any Community Opportunity claim remain outside this staging record until verified and accepted.
