## The two-minute path

1. **Overview / identity**
   - Confirm target, namespace, authority context, Observe Only state, and release identity.
   - Show that the interface morphs without changing the underlying semantic contracts.

2. **Command Palette**
   - Open with Ctrl/Cmd+K or the thumb-accessible command button.
   - Search a real IRIS entity/operation.
   - Point out that the schema-derived explorer extends breadth without giving unknown mutations execution authority.

3. **Operation Rehearsal**
   - Choose a qualified reversible mutation.
   - Rehearse it with zero dispatch.
   - Show observed pre-state, requested transition, authority, reversibility, and Impact Forecast.

4. **Plan Review / confirmation**
   - Demonstrate Observe Only refusing dispatch.
   - Disable Observe Only for the qualified fixture.
   - Confirm the exact current plan.

5. **Verified Receipt**
   - Execute once.
   - Show authoritative read-back and the resulting Verified Receipt.
   - Restore the fixture and show the second receipt.

6. **Session Ledger / Evidence**
   - Show the observation, rehearsal/plan, confirmation, receipts, findings/refusals as projections of one Evidence model.

7. **Packages**

8. **Semantic investigation**

9. **Targets / workflow / graph**

10. **Intelligence trust boundary**

    - External model provider choice does not become authority.
